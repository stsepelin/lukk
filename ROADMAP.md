# Roadmap

The roadmap for **lukk** (this package) and **lukk-js** (the client) — planned work plus the shipped
feature inventory — lives on the docs site, so both are in one place:

📍 **[stsepelin.github.io/lukk-docs/roadmap](https://stsepelin.github.io/lukk-docs/roadmap)**

Nothing there is a commitment. New features ship opt-in where they can; breaking changes are called out in CHANGELOG.md and UPGRADE.md. Have a use case that
needs a planned item — or something not listed? [Open an issue](https://github.com/stsepelin/lukk/issues).
Shipped work is detailed in the [CHANGELOG](CHANGELOG.md).
